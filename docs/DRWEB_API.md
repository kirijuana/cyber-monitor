# Dr.Web Web API — детальное описание

## 1. Общая архитектура API

Dr.Web Web API — HTTP/HTTPS-интерфейс для управления сервером Dr.Web и получения данных о защищённых станциях.

### Базовые эндпоинты

```
http://<host>:9080/api/<объект>/<сценарий>.ds?<параметры>
https://<host>:9081/api/<объект>/<сценарий>.ds?<параметры>
```

### Формат ответа

- По умолчанию — XML
- С параметром `?format=json` — JSON

### Объекты управления

- `stations` — станции
- `groups` — группы
- `server` — сервер Dr.Web
- `admins` — администраторы
- `quarantine` — карантин

### Структура JSON-ответа

```json
{
  "head": {
    "status": true,
    "time": "2024-01-01T12:00:00",
    "api_version": "4.3.x",
    "server_name": "drweb-server",
    "server_uuid": "..."
  },
  "data": {}
}
```

### Обработка ошибок

```json
{
  "head": { "status": false },
  "error": {
    "code": 403,
    "message": "Access denied"
  }
}
```

## 2. Станции (`/api/stations/`)

### Ключевые сценарии

| Сценарий | Назначение | Возвращаемые данные |
|----------|-----------|---------------------|
| `info.ds` | Информация о станции | ID, имя, группы, описание, время и адрес последнего подключения |
| `list-by-state.ds` | Список станций по статусу | Массив ID станций в заданном состоянии (online/offline) |
| `list-by-type.ds` | Список станций по типу | Массив ID по типу (рабочая станция, сервер и т.д.) |
| `state.ds` | Текущее состояние станции | Статус, время последнего подключения |
| `statistics.ds` | Статистика угроз | Топ вирусов, количество заражений, типы угроз |
| `installed-components.ds` | Установленные компоненты | Список компонентов с версиями |
| `running-components.ds` | Запущенные компоненты | Список активных компонентов |
| `products.ds` | Установленные продукты | Продукты Dr.Web на станции |
| `modules.ds` | Программные модули | Модули и их версии |
| `infections-chart.ds` | Статистика срабатываний | Данные для графика по времени |
| `hips_events.ds` | События Превентивной защиты | Лог HIPS-событий |
| `quarantine-objects.ds` | Объекты в карантине | Состояние карантина станции |
| `newbies-info.ds` | Новички | Станции, запросившие доступ |

### Статистика угроз (`statistics.ds`)

**Параметры запроса:**
- `id` — ID станции (обязательный)
- `top-viruses` — включить топ вирусов (yes/no, по умолчанию yes)
- `virtop` — количество вирусов в топе (по умолчанию 10)

**Структура ответа:**

```json
{
  "data": {
    "stations": {
      "list": [{
        "id": "1002",
        "name": "WIN7-PRO-X64-RU",
        "infections": {
          "scanned": 2697,
          "infected": 12,
          "cured": 1,
          "moved": 5,
          "deleted": 0
        },
        "viruses": {
          "Adware.Dudu": 1,
          "Trojan.DownLoader": 3
        },
        "viruses_info": {
          "Adware.Dudu": {
            "count": 1,
            "originator": 57,
            "treatment": 1049605
          },
          "Trojan.DownLoader": {
            "count": 3,
            "originator": 57,
            "treatment": 1049605
          }
        }
      }]
    }
  }
}
```

**Определение типа угрозы по названию:**
- `trojan` — троян
- `virus` / `win32` — вирус
- `worm` — червь
- `adware` — рекламное ПО
- `spyware` — шпионское ПО
- `riskware` — рискованное ПО
- `dialer` — дайлер
- `joke` — шутка
- `exploit` — эксплойт

### Поля станции

- `id` — уникальный идентификатор
- `name` — имя станции
- `groups` — группы с типами:
  - `0` — пользовательская
  - `1` — базовая
  - `2` — online
  - `3` — offline
  - `4` — по ОС
- `description` — описание
- `last_connect_time` — время последнего подключения
- `last_connect_address` — адрес последнего подключения
- `rights` — права
- `acl` — список доступов
- `license_keys` — привязанные лицензионные ключи

### Действия над станциями

- Создание / изменение / удаление
- Перезагрузка
- Запуск сканирования
- Обновление компонентов
- Восстановление из карантина

## 3. Сервер Dr.Web (`/api/server/`)

### Общая информация (`info.ds`)

**Возвращаемые данные:**

```json
{
  "data": {
    "server": {
      "hostname": "drweb-server",
      "id": "server-001",
      "name": "Dr.Web Server",
      "os": "Windows Server 2019",
      "platform": "x64",
      "version": "13.0.0",
      "build": "202005090",
      "uptime": 864000,
      "api_version": "4.3.0",
      "memory": {
        "total": 16384,
        "free": 8192,
        "used_by_server": 2048
      },
      "filesystem": {
        "path": "C:\\",
        "total": 500000,
        "free": 250000
      }
    },
    "stations": {
      "total": 150,
      "online": 120,
      "offline": 25,
      "activated": 140,
      "unactivated": 10,
      "new": 5,
      "with_update_errors": 3
    }
  }
}
```

**Поля:**
- `hostname` — имя хоста
- `id`, `name` — идентификатор и имя сервера
- `os` — операционная система
- `platform` — платформа
- `version` — версия сервера
- `build` — номер сборки
- `uptime` — время непрерывной работы (в секундах)
- `api_version` — версия API
- `memory.total` — общая память (МБ)
- `memory.free` — свободная память (МБ)
- `memory.used_by_server` — память, используемая сервером (МБ)
- `filesystem.total` — общий объём диска (МБ)
- `filesystem.free` — свободное место на диске (МБ)

### Статистика угроз (`statistics.ds`)

- Топ вирусов за период
- Динамика по времени
- Фильтрация по периоду (`from`, `till`)

### Репозиторий

- `repository-status.ds` — состояние репозитория
- `repository-products.ds` — продукты в репозитории

## 4. Карантин (`/api/quarantine/`)

### Возможности

- **Список объектов:** массив идентификаторов объектов в карантине
- **Детали объекта:**
  - `restore_path` — путь восстановления
  - `quarantine_time` — время помещения в карантин
  - `scan_report` — отчёт сканирования
  - `file_statistics` — статистика файла
  - `operations_history` — история операций
  - `owner` — владелец

### Действия

- Восстановить объект
- Удалить объект
- Экспорт

---

## 5. Администраторы и группы администраторов

- Управление администраторами (создание, редактирование, удаление)
- Управление группами администраторов
- Назначение прав и ACL
- Разграничение доступа к станциям и группам

## 6. События (для расширенного мониторинга)

### Лицензии

- `expire` — лицензия истекает
- `diff` — новый ключ с отличиями
- `renew` — лицензия обновлена

### Эпидемия

- `total` — общее число заражений
- `virus` — наиболее часто встречающийся вирус

### Контроль приложений

Структура события:

- `id` — ID станции
- `address` — адрес
- `station_name` — имя станции
- `time` — время
- `user` — пользователь
- `type` — тип события
- `action` — действие
- `policy` — политика
- `process`:
  - `path`
  - `SHA-256`
  - `version`
  - `description`

---

## 7. Структура ответа (общая)

Все ответы содержат блок `head` со служебной информацией:

| Поле | Описание |
|------|----------|
| `status` | `true` / `false` — успех запроса |
| `time` | Время сервера |
| `api_version` | Версия API |
| `server_name` | Имя сервера |
| `server_uuid` | UUID сервера |

При `status: false` добавляется блок `error` с `code` и `message`.
